# Backend boundary

Phase 1 implements FastAPI, Pydantic, SQLAlchemy, Alembic and real PostgreSQL/PostGIS integration. From the checkout root run `bash scripts/install.sh`, `bash scripts/start.sh`, and `bash scripts/test.sh`. Read [development setup](../docs/DEVELOPMENT.md), [schema](../docs/DATABASE_SCHEMA.md), [API](../docs/API_CONTRACT.md), [security](../docs/SECURITY.md) and [phase plan](../docs/IMPLEMENTATION_PLAN.md). Phase 3 adds the standard-library-only `app/routing` engine, repeatable-read PostGIS snapshot adapter and public `/api/v1/routes/calculate` API, with independent-oracle and real-DB concurrency tests. Phase 4 adds owner-scoped reporting, private bounded JPEG/PNG evidence, transactional review/restrictions, database analytics and durable SSE. Phase 5 adds an optional evaluated-asset registry, private leased jobs/predictions and annotation-only review; trained assets are unavailable. See [Phase 3 evidence](../docs/PHASE3_TEST_EVIDENCE.md) and [Phase 4 evidence](../docs/PHASE4_TEST_EVIDENCE.md).

Head `0003_ml` has 25 tables; core tests/startup do not require tensor dependencies. Read [Phase 5 evidence](../docs/PHASE5_TEST_EVIDENCE.md) and [ML commands](../ml/README.md).
